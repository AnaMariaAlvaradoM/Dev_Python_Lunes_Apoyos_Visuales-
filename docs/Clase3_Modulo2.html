01CONTEXTO

Antes del código existe una decisión de negocio

Punto de partida

¿Cómo convertir una veterinaria que trabaja con cuadernos en un sistema confiable?

Patitas Felices necesita registrar familias, mascotas, citas, veterinarios, tratamientos e insumos. El reto no es empezar a programar: es descubrir qué información importa, cómo se relaciona y qué reglas deben protegerse.

Caso de negocio

Patitas Felices

Un dueño puede registrar varias mascotas. Cada cita corresponde a una mascota y la atiende un veterinario. Los tratamientos consumen insumos del inventario y solo pueden aplicarse cuando existe stock suficiente para completar todo el procedimiento.

Modelo mental

Piensa en el sistema como un mapa de responsabilidades: las entidades representan protagonistas del negocio; las relaciones explican cómo colaboran; las reglas impiden que los datos contradigan la operación real.

02MODELADO

Entidades, atributos y relaciones

Entidad

Concepto del negocio con identidad y datos propios: Dueño, Mascota, Cita, Veterinario, Tratamiento e Insumo.

Atributo

Característica que describe una entidad. Por ejemplo, especie describe a Mascota; no necesita una tabla propia en este alcance.

Relación

Regla que conecta entidades: un Dueño tiene muchas Mascotas; una Mascota pertenece a un Dueño.

Cómo leer las relaciones

1:N: un dueño puede tener muchas mascotas. N:M: muchos tratamientos usan muchos insumos. Cuando la relación N:M necesita guardar la cantidad utilizada, aparece una tabla intermedia: la receta del tratamiento.

Criterio técnico

Las relaciones salen de las reglas del negocio, no de la tecnología. No conectes entidades “por si acaso” ni dupliques relaciones que ya pueden recorrerse indirectamente.

Comprueba tu criterio

¿Dónde debería vivir la cantidad de guantes que usa una vacuna?
En la tabla intermedia entre Tratamiento e Insumo, porque la cantidad pertenece a esa combinación específica, no a una entidad aislada.
03ARQUITECTURA

Cuatro capas, cuatro responsabilidades

Model

Representa tablas, columnas y llaves foráneas con SQLAlchemy.

Schema

Define el contrato de entrada y salida, incluyendo validaciones con Pydantic.

Service

Concentra la lógica de negocio y las operaciones sobre la base de datos.

Router

Expone endpoints HTTP y delega la operación al service.

Flujo de una petición

Cliente → Router → Schema valida → Service decide → Model persiste → respuesta validada. La separación permite cambiar una parte sin mezclar responsabilidades.

Error frecuente

Qué ocurre: el router termina lleno de consultas, validaciones y reglas.

Cómo leerlo: si el endpoint hace más que recibir, delegar y responder, probablemente tiene lógica que pertenece al service.

Cómo resolverlo: mueve la lógica de negocio al service y conserva el router como puerta HTTP.

05DATOS

Conectar FastAPI con PostgreSQL

Qué vamos a construir

La configuración central de SQLAlchemy.

Por qué

Todas las capas necesitan una forma segura y reutilizable de abrir y cerrar sesiones.

Qué aprenderás

Cómo trabajan engine, SessionLocal, Base y get_db.

CREARapp/config/database.py
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker, declarative_base

URL_CONEXION = "postgresql+psycopg://postgres:TU_CONTRASENA@localhost:5432/patitas_vet"

engine = create_engine(URL_CONEXION)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()


def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

Engine

Punto de acceso de SQLAlchemy hacia PostgreSQL.

SessionLocal

Fábrica que crea sesiones de trabajo para consultar y modificar datos.

yield

Entrega temporalmente la sesión y permite retomarla después para cerrarla, incluso si ocurre un error.

Configuración necesaria

Reemplaza TU_CONTRASENA por la contraseña local de PostgreSQL y crea previamente la base patitas_vet en pgAdmin.

CREARapp/schemas/dueno_schemas.py
from pydantic import BaseModel, Field, EmailStr, field_validator


class DuenoCreate(BaseModel):
    nombre: str = Field(..., min_length=2, max_length=60)
    telefono: str = Field(..., min_length=7, max_length=15)
    email: EmailStr

    @field_validator("nombre")
    @classmethod
    def nombre_no_vacio(cls, valor: str) -> str:
        limpio = valor.strip()
        if limpio == "":
            raise ValueError("El nombre no puede estar vacío")
        return limpio


class DuenoRespuesta(BaseModel):
    id: int
    nombre: str
    telefono: str
    email: str

    class Config:
        from_attributes = True

Separación clave

El model almacena el email como texto; el schema valida que realmente tenga formato de correo. Persistencia y validación no son la misma responsabilidad.

Dependencia adicional

Si aparece un error relacionado con email-validator, ejecuta pip install "pydantic[email]".

CREARapp/services/dueno_service.py
from sqlalchemy.orm import Session
from app.models.dueno_model import Dueno
from app.schemas.dueno_schemas import DuenoCreate


def crear_dueno(db: Session, datos: DuenoCreate):
    nuevo = Dueno(
        nombre=datos.nombre,
        telefono=datos.telefono,
        email=datos.email,
    )
    db.add(nuevo)
    db.commit()
    db.refresh(nuevo)
    return nuevo


def listar_duenos(db: Session):
    return db.query(Dueno).all()


def obtener_dueno(db: Session, dueno_id: int):
    return db.query(Dueno).filter(Dueno.id == dueno_id).first()


def actualizar_dueno(db: Session, dueno_id: int, datos: DuenoCreate):
    dueno = db.query(Dueno).filter(Dueno.id == dueno_id).first()
    if dueno is None:
        return None
    dueno.nombre = datos.nombre
    dueno.telefono = datos.telefono
    dueno.email = datos.email
    db.commit()
    db.refresh(dueno)
    return dueno


def eliminar_dueno(db: Session, dueno_id: int):
    dueno = db.query(Dueno).filter(Dueno.id == dueno_id).first()
    if dueno is None:
        return False
    db.delete(dueno)
    db.commit()
    return True

Regla de oro

Crear, actualizar o eliminar no modifica PostgreSQL hasta ejecutar commit().

CREARapp/routers/dueno_router.py
from fastapi import APIRouter, Depends, HTTPException
from sqlalchemy.orm import Session
from app.config.database import get_db
from app.schemas.dueno_schemas import DuenoCreate, DuenoRespuesta
from app.services import dueno_service

router = APIRouter(tags=["Dueños"])


@router.post("/duenos", response_model=DuenoRespuesta)
def crear(datos: DuenoCreate, db: Session = Depends(get_db)):
    return dueno_service.crear_dueno(db, datos)


@router.get("/duenos", response_model=list[DuenoRespuesta])
def listar(db: Session = Depends(get_db)):
    return dueno_service.listar_duenos(db)


@router.get("/duenos/{dueno_id}", response_model=DuenoRespuesta)
def obtener(dueno_id: int, db: Session = Depends(get_db)):
    dueno = dueno_service.obtener_dueno(db, dueno_id)
    if dueno is None:
        raise HTTPException(status_code=404, detail="Dueño no encontrado")
    return dueno


@router.put("/duenos/{dueno_id}", response_model=DuenoRespuesta)
def actualizar(dueno_id: int, datos: DuenoCreate, db: Session = Depends(get_db)):
    dueno = dueno_service.actualizar_dueno(db, dueno_id, datos)
    if dueno is None:
        raise HTTPException(status_code=404, detail="Dueño no encontrado")
    return dueno


@router.delete("/duenos/{dueno_id}")
def eliminar(dueno_id: int, db: Session = Depends(get_db)):
    eliminado = dueno_service.eliminar_dueno(db, dueno_id)
    if not eliminado:
        raise HTTPException(status_code=404, detail="Dueño no encontrado")
    return {"mensaje": f"Dueño {dueno_id} eliminado"}

CREARapp/models/mascota_model.py
from sqlalchemy import Column, Integer, String, Date, ForeignKey
from sqlalchemy.orm import relationship
from app.config.database import Base


class Mascota(Base):
    __tablename__ = "mascotas"

    id = Column(Integer, primary_key=True, index=True)
    nombre = Column(String, nullable=False)
    especie = Column(String, nullable=False)
    raza = Column(String, nullable=True)
    fecha_nacimiento = Column(Date, nullable=True)

    dueno_id = Column(Integer, ForeignKey("duenos.id"), nullable=False)

    dueno = relationship("Dueno")

from sqlalchemy.orm import Session
from fastapi import HTTPException
from app.models.mascota_model import Mascota
from app.models.dueno_model import Dueno
from app.schemas.mascota_schemas import MascotaCreate


def crear_mascota(db: Session, datos: MascotaCreate):
    dueno = db.query(Dueno).filter(Dueno.id == datos.dueno_id).first()
    if dueno is None:
        raise HTTPException(status_code=404, detail="El dueño indicado no existe")

    nueva = Mascota(
        nombre=datos.nombre,
        especie=datos.especie,
        raza=datos.raza,
        fecha_nacimiento=datos.fecha_nacimiento,
        dueno_id=datos.dueno_id,
    )
    db.add(nueva)
    db.commit()
    db.refresh(nueva)
    return nueva


def listar_mascotas(db: Session, dueno_id=None):
    consulta = db.query(Mascota)
    if dueno_id is not None:
        consulta = consulta.filter(Mascota.dueno_id == dueno_id)
    return consulta.all()


def obtener_mascota(db: Session, mascota_id: int):
    return db.query(Mascota).filter(Mascota.id == mascota_id).first()


def eliminar_mascota(db: Session, mascota_id: int):
    mascota = db.query(Mascota).filter(Mascota.id == mascota_id).first()
    if mascota is None:
        return False
    db.delete(mascota)
    db.commit()
    return True
