    🔑 Tu token JWT

    Authorization: Bearer …

    Cualquiera puede leer el contenido (solo está codificado en Base64, no cifrado). Por eso no lleva la contraseña ni el rol. Lo que nadie puede hacer es modificarlo: la firma dejaría de coincidir y la API respondería 401.
